# BipBom

Telegram-бот с мини-играми, кейсами, кошельком и WebApp-страницей.

## Валюты

| Валюта | Где живёт | Для чего | Что нельзя |
|---|---|---|---|
| ☭ Кредиты (демо) | `users.balance` | только игра и кейсы | купить, обменять, вывести |
| ₽ Рубли | `wallet` (`rub`, копейки) | поддержка бота (благодарность) | ставить в игре, вывести |
| ⭐ Stars | `wallet` (`stars`) | разблокировка оформления | ставить в игре, обменять на кредиты |

Правило одно: **в ставках и кейсах участвуют только кредиты**. Они не покупаются за рубли или Stars и не обмениваются обратно. Рублёвый платёж и Stars-платёж ничего не дают в игре — это покупка вне игрового оборота.

## Запуск бота

1. Токен от @BotFather для `@BipBom_Off_bot`.
2. Двойной клик `start.cmd`, вставьте токен и Telegram ID для админки.
3. В Telegram: `/start`.

## Пополнение

- **Stars**: кнопка «⭐ Оформление за Stars» — инвойс в XTR, 50 звёзд. Работает сразу, если аккаунт бота принимает Stars.
- **Рубли**: кнопка «Пополнить рубли». Без `PROVIDER_TOKEN` Telegram отправляет тот же инвойс в Stars (Stars продаются в приложении). Для настоящих рублей нужен платёжный провайдер: @BotFather → Payments → подключить ЮKassa → получить provider token → задать `PROVIDER_TOKEN` в `start.cmd`.
- Кредиты не пополняются ничем.

## Админка (`ADMIN_ID`)

- `/admin` — пользователи, записи лога, суммы по валютам
- `/admin ledger <id>` — последние 10 операций с валютой
- `/admin bet <id> <лимит>` — лимит ставки
- `/admin refund <charge_id>` — возврат Stars через `refundStarPayment`; рубли — в панели провайдера
- `py bot.py grant <id> <кредиты>` — выдать кредиты вручную с сервера

## WebApp через ngrok

1. Зарегистрируйтесь на ngrok.com (бесплатно) и скопируйте authtoken.
2. Двойной клик `webapp.cmd` — скрипт сам скачает ngrok в `%LOCALAPPDATA%\ngrok`, попросит токен, поднимет локальный сервер на `127.0.0.1:8080` и туннель, выведет адрес вида `https://xxxx.ngrok-free.app/`.
3. Адрес сохраняется в `.webapp_url`. В @BotFather: `/setmenubutton` → ваш бот → вставьте адрес. Или Configure menu button.
4. Перезапустите `start.cmd`: кнопка «Открыть BipBom WebApp» появится в меню бота и ссылка подхватится автоматически.
5. Окно `webapp.cmd` должно оставаться открытым, пока пользуетесь WebApp. Закрыли — ссылка перестанет работать, запустите снова.

Бесплатный ngrok выдаёт новый адрес при каждом запуске: после перезапуска заново выполните `/setmenubutton`. Постоянный адрес — платный (или свой домен).

## Что не реализовано намеренно

Вывод средств, ставки за реальные деньги, обмен Stars/₽ ↔ кредиты. Платные покупки дают только оформление/поддержку, но не игровые ценности.

## Файлы

- `bot.py` — бот
- `web/index.html` — интерфейс
- `serve.py` — локальный сервер для WebApp
- `webapp.cmd` / `webapp.ps1` — запуск ngrok вместе с сервером
- `bipbom.db` — SQLite, создаётся и мигрируется сама
